# PE-Core CLEVR-4 frozen-feature readout protocol

## Question

Can the frozen, pinned PE-Core T16 image/text embeddings support a small
option-conditioned Decision readout on CLEVR-4, despite poor direct zero-shot
similarity? This is a development probe, not a product-quality claim.

## Frozen conditions

Use the exact encoder revision and converted-weight hash in
[`pe_core_clevr4_frozen_readout.yaml`](../../configs/pretrained_reuse/pe_core_clevr4_frozen_readout.yaml).
Freeze all 69,546,113 encoder parameters. For each supplied option, concatenate
the L2-normalized 512-d image embedding with the L2-normalized 512-d text
embedding generated by the already frozen prompt templates in the zero-shot
protocol. Train one shared 1024→128 GELU→1 scorer (131,330 trainable parameters)
with option softmax. Use seed 17, AdamW at 1e-3, weight decay 1e-4, 8 epochs,
and 64 questions per batch. Do not search prompts, architecture, hyperparameters,
or seeds.

Use the existing CLEVR-4 training split (8,424 images) and fixed 512-image
checkpoint-selection split. Select the checkpoint by minimum validation NLL.
After configuration and selected checkpoint are frozen, evaluate once on the
disjoint, previously observed 1,595-image reporting subset. Compare against the
already retained Path A and PE-Core zero-shot predictions on identical IDs and
options; label both as development comparisons. Do not load sealed audit data.

Save the feature cache, effective config, split/media hashes, per-epoch train
loss and validation Accuracy/NLL/Brier/ECE, selected checkpoint, full validation
and reporting predictions, parameter counts, runtime and peak VRAM to the new
attempt-04 output directory specified in the config. Never overwrite prior
attempts. Run all GPU work through the cooperative HotUGPU reservation wrapper;
it must observe external GPU yield and reserve memory before starting the child.
If the reservation cannot be obtained, leave the attempt unstarted and report
that state.

## Interpretation

This single seed and synthetic task can establish whether a small learned
readout recovers useful performance on this task. It cannot establish natural
image generalization, broad modality quality, an independent test result, or
product readiness. A failure does not prove the encoder representation ceiling.
