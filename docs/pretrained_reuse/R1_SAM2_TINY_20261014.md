# SAM 2.1 Tiny: executed local admission, functional only

## Why this probe

The completed Lombard pooled comparison did not establish useful video
contribution. Earlier TAPIR diagnostics improved some motion errors but required
annotated initial points; later small readouts did not establish semantic Decision
quality. A pretrained object-mask/memory model is a distinct representation
candidate. This **R1 spike** measures checkpoint compatibility, complete parameter
cost and existing Windows/local GPU feasibility before any new training.

The user's autonomous strategy/public-data instruction covers this bounded local
probe. External probe scripts are throwaway research artifacts, not a production
provider. No new architecture/Teacher, hyperparameter search or release is implied.

## Fixed input and runtime contract

Windows, existing RTX3080 Laptop16GiB, Python3.11.9,Torch2.6.0+cu124,
CUDA12.4,Transformers5.6.2,NumPy2.4.6,PyAV18.1.0. FP32, SDPA,
deterministic algorithms, TF32 off, no compilation/AMP/training. No CUDA extension
installation, virtualenv-launcher workaround, WSL setup or package upgrades.
Preflight required12GiB free GPU; safe cap6GiB peak Torch allocation/400s.

Input is RGB plus **one positive point at the geometric image center**, one
object ID. Prompt labels are click signs, not corpus/class labels. No annotation,
transcript, source name or target is fed to the model. This fixed geometric point
is **not automatic semantic discovery**, and may select background or an unsuitable
object. It only avoids a ground-truth-derived prompt; it does not solve arbitrary
target selection or prove object correspondence.

The first frame exercises mask/vision processing; subsequent frames exercise
memory propagation. There is no separate standalone-image quality test. Fixed
two-frame synthetic RGB rectangles first test execution/repeat/reload. Four
predeclared **training** Lombard reference clips then use exactly the native
baseline's16 actual-PTS frame indices:
`s16_l_bgah2n`, `s16_p_bgah2n`, `s22_l_sgbe5s`, `s22_p_sgbe5s`.
Original media SHA and full archive SHA verified. Processor uses its published
1024×1024 resize/profile. This differs from VideoPrism's288 crop, so these are
not matched-backbone quality/latency comparisons. The same baseline corpus,
config, features and checkpoints were not changed.
