# Physion++ blinded train review pack — 2026-11-28

## Result

Built a deterministic, label-blinded review package from the preselected 75
exact-recorded-factor-matched No/Yes train pairs. It contains 32 evenly spaced
frames per clip, preserving each source frame's 256×256 resolution. Pair order
and left/right placement are randomized with seed `20261128`. Images contain
review IDs only; target labels and sample IDs are held in a separate private
key directory. The annotation CSV records left/right contact, uncertainty or
occlusion, evidence notes, and reviewer identity.

The package was generated by
`scripts/build_physionpp_blinded_review_pack.py`; its unit tests are in
`tests/test_build_physionpp_blinded_review_pack.py`.

## Review status and limits

This is a review instrument, not a completed human review. No observer scores
have been entered and the answer key must remain unopened until a reviewer has
saved all judgments. A reviewer should receive only the `images` directory,
use the CSV template, judge left and right independently, and mark occluded or
ambiguous cases as uncertain. The paired sample is train-only and previously
observed; it cannot support blind model-quality claims or replace an
independent dataset audit.
