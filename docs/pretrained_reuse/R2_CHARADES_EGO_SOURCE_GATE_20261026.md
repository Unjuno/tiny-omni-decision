# Charades-Ego source gate — 2026-10-26

## Decision

**Do not admit Charades-Ego as a product-aligned training or AV-quality source on the evidence currently available.** The former official project page is still indexed with dataset details, but now redirects to the general Allen AI homepage and no longer exposes the linked dataset terms. A published licensing table classifies Charades-Ego as non-commercial; that is not a replacement for the governing source terms, but it is enough to keep product use unresolved. The reviewed official description also does not establish that the released clips include usable audio or a task requiring audio and video jointly.

No annotations, archives, or media were downloaded or opened.

## Task and provenance screen

The indexed official project description characterizes Charades-Ego as paired first-/third-person videos of daily indoor activities, with 7,860 videos and 68,536 temporally annotated instances. This could support a video activity task, but paired viewpoints do not themselves prove audio-video complementarity, and the reviewed description does not identify audio as an input modality.

The old [official dataset page](https://prior.allenai.org/projects/charades-ego) currently redirects to Allen AI's general homepage, so its linked license and data terms could not be rechecked at this screen. A [published supplemental licensing table](https://proceedings.neurips.cc/paper_files/paper/2023/file/a86d17b6cd70366d56ab48d2a05a4df1-Supplemental-Conference.pdf) lists Charades-Ego as “Non-commercial use.” Treat this as a rights warning, not as the authoritative license text.

## Gate result

- Video task relevance: **possible**.
- Audio asset availability and both-input necessity: **not established**.
- Current authoritative reuse terms: **not verifiable from the official page**.
- Product-aligned training/evaluation admission: **REVIEW / do not use pending rights and modality evidence**.
- Data payload accessed: **no**.

Reconsider only if the dataset provider restores or supplies authoritative current terms covering the intended use, and confirms the available audio/video assets, source grouping, and a task contract for any claimed joint-modality evaluation.
