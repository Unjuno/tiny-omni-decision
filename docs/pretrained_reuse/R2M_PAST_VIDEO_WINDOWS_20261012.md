# Past-only video window extraction: measured implementation

## Fixed input protocol and implementation

Following the measured noncausal context in the current VideoPrism encoder,
implement eight distinct endpoint-spaced frames confined to an inclusive
four-second window. The selector rejects invalid timestamps, reversed bounds
and fewer than eight available frames. It never pads a short window with
future frames. Unit tests compare selection with and without future timestamps.

Executed **one training clip only**, S40_A01_T01, nine windows ending at
4,8,...,36seconds; no schedule or clip search. The sampler uses window-local
observed timestamps, not whole-episode frame spacing. Adjacent windows share
their boundary frame; they are not independent examples. Split grouping must
remain at the original subject/trial level if future experiments use windows.

This probe decodes a recorded file in two passes to extract the selected frames.
It is **not a live capture loop**. Input selection is prefix-consistent; the
complete offline process is not an online latency measurement. No window labels
were generated by copying the episode activity label, and no classifier was
trained or evaluated on these shorter inputs.
