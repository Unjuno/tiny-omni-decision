# MUSIC-AVQA v2 source admission

New follow-up to the previously reviewed AVQA/MUSIC-AVQA candidates. The official
v2 publisher README describes a bias-balancing extension and research-purpose-only
YouTube videos. Therefore it is not admitted as ALLOW training media under the
current project constraints. No data, questions or videos were downloaded; only
README/provenance were archived. Repository license alone does not establish
permissions for every underlying media asset. This is an admission decision,
not a legal opinion or evidence that no usable AV source exists.

The README identifies multiple clips from the same original video and horizontal
flips paired with symmetric questions. Any future permitted use must group these
by source video, not filename. Balanced labels also do not remove the need for
question-only, audio-only, video-only and shuffled-evidence controls.
