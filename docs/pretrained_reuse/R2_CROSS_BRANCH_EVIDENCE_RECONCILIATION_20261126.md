# R2 cross-branch evidence reconciliation — 2026-11-26

## Purpose and disposition

This note reconciles material R2 results published on independent experiment branches after the latest entry on the pretrained-reuse roadmap branch (`32767c281de0de1504973e8a79de37621f9c2fc6`). It prevents duplicate evaluation and records what the evidence changes about the next experiment. It does not merge experiment branches, promote a model, or close R2.

**Decision:** retain compact BERT-family encoders as task-specific text candidates and possible teachers. Do not run another broad BERT sweep on exposed tasks. The recent results include strong gains on some Japanese text decisions, failures or weak transfer on others, and one four-modality integration with mixed effects. None establishes the requested general text/image/audio/video Decision quality or the R2 multi-input gate. The next BERT comparison requires a newly admitted task with rights and source grouping resolved before model fitting. For the Omni objective, R2 still needs a valid task where aligned streams matter and joint quality beats matched single-stream controls.

## Multimodal evidence and current source gate

The expanded RoboPro Path A result (`codex/r2-robopro-path-a-result-20261126` (`a6edb77b61dd935cde26c7eab37d144119bdc9a0`)) used 64 development prompt groups. State-only reached 75.65% Accuracy / 0.5478 NLL; State+Video-GRU reached 64.58% / 0.7425; Text+State+Video-GRU reached 61.72% / 0.8017. Video ablations show that the joint readout responds to aligned video, but adding video did not improve over state-only. The target is a recorded demonstrator action rather than task success, physical scene independence is unknown, and the development set was used for checkpoint selection. This is a task-specific negative result, not a general video-capability limit.

The latest MotorSense screen (`codex/r2-motorsense-source-screen-20261126` (`dc3f4d68b1422773774df978e9d374646c93ae80`)) remains `REVIEW_NOT_ADMITTED`: its dataset license is `other`, the paper and Hub disagree on released face blurring, action validation participants overlap training or are unattributed, and its released representation was pretrained on validation recordings. Do not download or use its payload/checkpoint for a quality experiment until those gates are resolved.

## Next experiment gate

1. Do not repeat or tune on KUCI Dev, Jamp test, JAQKET Dev2, XCOPA validation, the matched Path A validation, or RoboPro development groups.
2. Keep BERT-base as a text teacher/reference. A compact BERT-family candidate can receive one matched comparison only after an unexposed, rights-admitted, source-grouped text Decision task and a frozen validation protocol exist.
3. Prioritize R2 admission of a naturally recorded multi-input task with verified rights, group-disjoint splits, an unambiguous decision target, and matched unimodal/joint/input-perturbation controls. Source identity and task semantics must be checked before fitting.
4. Keep all quality claims task-specific. No current result closes R2, demonstrates 95–98% across modalities, or qualifies a product runtime.

No model, data, checkpoint, or existing run was changed by this reconciliation. Sealed audit data was not accessed. The local RTX 3080 was occupied by an existing Python training process during this review; no GPU work was started.
