# Bare-finger contact source feasibility protocol

Purpose: assess a directly accessible public native contact source for supplied-option
texture decisions with audio/force/vibration/image controls. This does not replace
the full text/image/audio/video <=200M Omni objective or assume useful joint input.

Primary release: `doi:10.6084/m9.figshare.26965267.v1`, official article version1,
CC BY4.0. Preserve attribution. Only bounded immutable metadata/ZIP-directory
reads and one fixed format pilot are authorized here; no training, checkpoint
selection, new split or final-test inspection. All500 physical trials must remain
visible. Expect10 participants,10 texture identities, five trials per pair;200
stereo photos are texture-level observations, not participant-specific video.

Directory metadata records ZIP names, lengths, offsets, CRC and methods. Partial
HTTP ranges cannot prove full20GB archive MD5. Payload CRC/local SHA verifies
only the fetched member. Never execute supplied notebooks/Python/pyc or unpickle.
Read-only upstream source inspection does not establish permission to adopt code.

Audit exact participant/texture/trial names and full Cartesian coverage, image
texture/camera/shot coverage, unique safe member paths and physical grouping.
Do not confuse500 trials with500 independent photographed objects. A participant
split keeps trials separate but cannot make shared texture photos independent.
No repeated photo may cross train/validation. Material/specimen/condition/OOD
semantics and all necessary independent validation gates remain open.

The fixed native pilot is `subject_0/7t/std_0`, `7t_l_0.jpg` and the existing
texture calibration JSON. It is a source-format pilot with no train/eval role.
Inspect numeric HDF5 datasets/links/filters/shapes/timestamps/finite values before
admitting streams; retain native values, units and calibration uncertainty.
No gain normalization, clock invention, force calibration or resampling here.
The paper's prose rates/units are hypotheses to compare against actual arrays.
Position traces are not native RGB video; fixed photos do not establish video.

Immutable receipts and raw source bytes remain outside Git. The metadata auditor
binds the source receipt/directories/code/tests/protocol before parsing,
terminal-rechecks sources, writes a new path only and never imports HDF5/model
libraries. The separate native producer binds pilot receipt/bytes plus its own
numeric helper, dependencies and isolated HDF5 runtime. It inspects only standard
numeric datasets, with external/soft links, virtual/external storage and unknown
filters rejected. CPU60s,1GiB peak,1MiB report,1GiB disk reserve. Existing GPU8GiB guard
and interrupted runs remain unchanged. PASS is source accounting only; independent
validation, full-media/content checks, source clock, quality and training admission
remain unverified. Negative/unknown findings are retained.
