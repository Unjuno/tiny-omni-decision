# AVRT-20K source gate (2026-10-24)

## Disposition

**REVIEW / not admitted to multimodal training or evaluation.** AVRT-20K is a
potentially useful task-design reference because its card reports four-choice
audio-video questions with a `question_relation` field and a large majority
marked `Both`. It does not presently provide a rights-cleared, group-split local
AV source for this project. No dataset rows, media, test labels, or model output
were downloaded or opened in this screen.

## Metadata-only evidence

- Dataset card: <https://huggingface.co/datasets/CVML-TueAI/AVRT-20K>, pinned
  repository HEAD `9cfc00e134d8b189bb2e5bb045f47837cb881ddb` (queried with
  `git ls-remote`; metadata only).
- The card declares CC-BY-4.0 for the hosted annotations and states that it
  contains 40,182 rows in one split, `af3_kimivl`. The row schema includes
  `video_id`, `video_name`, question, four choices, answer, question relation,
  type, and an AV reasoning field. A source-group partition could be derived
  by `video_id`, but there is no published train/validation split to inherit.
- The card says AVQA is the source dataset and the source videos must be
  obtained separately under AVQA's terms. The project's pinned AVQA rights
  recheck found no dataset/media license and a GitHub repository `license:
  null`; YouTube/VGGSound video rights remain unresolved. The annotation mirror's
  CC-BY declaration does not grant rights to those videos or supersede that
  component-level restriction. See
  [`R2_AVQA_RIGHTS_RECHECK_20261021.md`](R2_AVQA_RIGHTS_RECHECK_20261021.md).
- The card says its reasoning traces were generated by Audio Flamingo 3,
  Kimi-VL-Thinking, and Qwen2.5-14B-Instruct; only examples where both
  single-modality teachers were correct were retained. The `Both` metadata is
  therefore a task annotation, not independent proof that both streams are
  necessary. Teacher filtering/trace fields also create leakage risks if used
  as inputs or targets without a separate audit.

## Gate to reopen

Reopen only after rights to the exact AVQA media and annotation components are
explicit, and a pinned, locally usable TRAIN subset can be grouped by underlying
video with train/validation disjointness. If admitted later, exclude reasoning
traces from model inputs, check answer/teacher leakage, evaluate matched
audio-only, video-only, and joint controls, and verify a both-input-required
label protocol independently. Do not use the one published split as a blind
audit or silently split individual question rows.

No media/annotation files were downloaded, no model was loaded, and no GPU,
cloud compute, or existing process was used. This closes neither R2-M-2 nor the
product AV quality gate.
